# RootScope 固定式根区灌溉舱：硬件连接与安全规范

> 版本：P0 / 2026-07-14  
> 边界：固定桌面舱；无底盘、轮电机、LiDAR、IMU、深度相机、SLAM、Nav2。  
> P0 只保留 `1×RDK X5 + 1×STM32F407 + 1×固定 UVC 相机 + 3×独立微型蠕动泵 + 称重/互锁`。

配套图：

- `rootscope_signal_wiring.svg`：信号和数据连接。
- `rootscope_power_estop.svg`：供电、急停和执行器失能链。

## 1. 状态标签

| 标签 | 含义 |
|---|---|
| **XRD 已验证** | 已在现有 XRD F407 源码或现场记录中明确配置；不等于 RootScope 整机已验证。 |
| **RootScope 冻结** | 本版产品架构确定采用，但仍要按实物端子和铭牌接线。 |
| **候选待冻结** | 可作为首版 PCB/洞洞板引脚；焊接前必须完成板卡原理图、现有固件复用和引脚冲突审计。 |
| **P0 不装** | 三天版本明确移除，不采购、不接线、不写驱动。 |

## 2. P0 总连接

```text
固定 UVC 相机 ──USB──> RDK X5
RDK X5 ──USB──> CH340/同类 USB-TTL ──3.3 V TTL──> STM32F407 USART2

称重片 ──> HX711 ──GPIO──> F407
Start / Reset / E-stop 辅助触点 / 护罩 / 沙芯到位 / 漏水 ──GPIO──> F407
F407 ──低压逻辑──> 3 路驱动输入 ──> 30/60/90 mm 三路独立微型蠕动泵
F407 ──只能撤销的 ACT_ENABLE──> K1 执行器接触器/功率继电器

HDMI/浏览器屏幕 <── RDK X5（只做本地展示，不依赖公网）
```

三路泵从同一个称重水箱取水，各自使用独立软管直达 30/60/90 mm 出水口。固件必须保证同一时刻最多一台泵运行；每台泵分别标定“质量变化—时间”曲线。水箱完整放在称重片托盘上，三根软管均留松弛环，不得用绑带、硬管或电缆形成旁路承重。为抑制停泵后虹吸，出水口高差和管路走向必须做实物断电滴漏测试；必要时再加防虹吸结构。

“一泵 + 三阀歧管”只作为赛后降成本备选，P0 不采购阀、不写阀时序，避免三天内引入歧管串水、死腔和切换故障。

## 3. RDK X5 与 F407 串口：直接复用 XRD 物理链

### 3.1 接线

| 连接 | F407 端 | USB-TTL 端 | 状态 |
|---|---|---|---|
| F407 发送 | `PD5 / USART2_TX` | `RXD` | **XRD 已验证** |
| F407 接收 | `PD6 / USART2_RX` | `TXD` | **XRD 已验证** |
| 信号参考 | `GND` | `GND` | **RootScope 冻结** |
| 供电 | F407 由逻辑电源独立供电 | USB-TTL 由 X5 USB 供电 | **RootScope 冻结**；USB-TTL 的 `VCC/5V` 不接 F407 |
| 串口参数 | `115200 8N1` | `115200 8N1` | **XRD 已验证** |

要求：

- 选用 3.3 V TTL 电平兼容的 USB-TTL；不得把 RS-232 电平直接接入 F407。
- 端口用 udev 固定为 `/dev/ROOTSCOPE_F407`，不得依赖 `/dev/ttyUSB0` 枚举顺序。
- USB-TTL 与 F407 独立供电时只共地、不连接模块 VCC，避免反向供电。
- 首次上电先只接 `TX/RX/GND` 做环回和身份读取，执行器母线保持断开。

源码依据：

- [`bsp_uart.c`](../../../embodied_brain/stm32_f407/App/bsp_uart.c)：`PD5=USART2_TX`、`PD6=USART2_RX`、115200、CH340 交叉接线。
- [`LIFT_STAGE_README.md`](../../../embodied_brain/stm32_f407/LIFT_STAGE_README.md)：现场使用的主机串口和安全语义。

### 3.2 复用的帧与安全语义

XRD 帧格式是：

```text
[0xAA] [0x55] [type u8] [len u8] [payload 0..251 B] [sum8]
```

`sum8` 从第一个 `0xAA` 累加到 payload 末尾；不是 CRC。多字节数值沿用小端。RootScope 复用帧壳、解析器、ACK、心跳和急停类型，但必须分配新的灌溉 payload，并生成新的协议版本、能力位、build id 和 `ROOTSCOPE` 硬件变体；X5 发送任何启泵命令前必须精确匹配身份。

| 类型/状态 | 复用规则 |
|---|---|
| 下行 `0xFF HEARTBEAT` | X5 以 5 Hz 发送；F407 侧超时门限沿用 1000 ms。 |
| 下行 `0x10 EMERGENCY_STOP` | 锁存停机；RootScope 扩展为三泵 OFF、`ACT_ENABLE` 撤销、当前 cycle 进入 `ABORTED_LOCKED`。 |
| 下行 `0x11 CLEAR_ESTOP` | 只在心跳新鲜且现场互锁全部恢复后接受；必须有显式人工 Reset/Clear，禁止自动恢复。 |
| 上行 `0x03 SAFETY_STATE` | 上报锁存、硬互锁、失联、漏水和拒绝计数；payload 需升级，不能冒充旧 4 字节定义。 |
| 上行 `0x04 FIRMWARE_INFO` | RootScope 使用独立身份；禁止沿用旧底盘 build id。 |
| 上行 `0x10 ACK` | `0=OK`、`3=ESTOP_LATCHED`、`4=LINK_STALE` 继续保留；RootScope 新增互锁拒绝码须同步 X5/F407 两端。 |

已有定义依据：[`proto.h`](../../../embodied_brain/stm32_f407/App/proto.h)、[`serial_protocol.hpp`](../../../embodied_brain/ros2_ws/src/my_robot_drivers/include/my_robot_drivers/serial_protocol.hpp)。

## 4. F407 引脚表

### 4.1 已验证资源与本版处置

| F407 引脚 | XRD 现有用途 | 证据级别 | RootScope P0 处置 |
|---|---|---|---|
| `PD5` | USART2 TX → USB-TTL | XRD 已验证 | 保留为主机串口 TX |
| `PD6` | USART2 RX ← USB-TTL | XRD 已验证 | 保留为主机串口 RX |
| `PC9` | TIM8_CH4，升降步进 PUL | XRD 已验证 | **不接**；可选机械轴预留 |
| `PD7` | 升降步进 DIR | XRD 已验证 | **不接**；可选机械轴预留 |
| `PD10` | 升降步进 EN，现有定义为低有效 | XRD 已验证 | **不接**；可选机械轴预留 |
| `PE0` | 电磁铁逻辑输出，高有效 | XRD 已验证为 GPIO | 候选映射为 30 mm 泵驱动输入；仍需核对极性 |
| `PC13` / `PC0` | 推杆继电器逻辑输出 | XRD 已验证为 GPIO | 候选映射为 60 / 90 mm 泵；仅驱动高阻输入 |
| `PB8` | TIM4_CH3 舵机 PWM | XRD 已验证为复用功能 | P0 不用；保留为状态灯/蜂鸣器候选 |

步进资源依据：[`bsp_lift.h`](../../../embodied_brain/stm32_f407/App/bsp_lift.h)。XRD 旧升降轴存在开环、掉步和驱动保护历史，所以 P0 不安装移动探针，也不把旧升降机构当作可复用实物证据。

### 4.2 RootScope 候选引脚分配

> 下表是布线候选，不是“已验证接线”。硬件队在焊接前应输出一份实际 F407 核心板引脚图，并逐项确认 3.3 V 电平、上电默认态、调试口和板载外设占用。

| 逻辑名 | 候选引脚 | 方向/默认 | 外部连接 |
|---|---:|---|---|
| `PUMP_30_GATE` | `PE0` | 输出，默认 0 | → 30 mm 泵的 3.3 V 兼容驱动输入；不得直驱泵 |
| `PUMP_60_GATE` | `PC13` | 输出，默认 0 | → 60 mm 泵驱动输入；PC13 只接高阻逻辑输入 |
| `PUMP_90_GATE` | `PC0` | 输出，默认 0 | → 90 mm 泵驱动输入 |
| `ACT_ENABLE` | `PC1` | 输出，默认 0 | → K1 线圈控制级；F407 只能撤销执行器许可 |
| `HX711_SCK` | `PB10` | 输出，默认 0 | → HX711 SCK |
| `HX711_DOUT` | `PB11` | 输入，上拉按模块核验 | ← HX711 DOUT；必须保证不超过 F407 IO 电平 |
| `CARTRIDGE_OK_NC` | `PB12` | 输入，断线=故障 | ← 沙芯抽屉常闭到位回路 |
| `GUARD_OK_NC` | `PB13` | 输入，断线=故障 | ← 透明护罩常闭回路，同时硬件串入 K1 链 |
| `LEAK_OK_NC` | `PB14` | 输入，断线/漏水=故障 | ← 接水盘漏水模块的隔离干接点 |
| `ESTOP_OK_NC` | `PB15` | 输入，断线/按下=故障 | ← 急停第二组常闭辅助触点 |
| `START_BTN` | `PC4` | 输入，去抖 | ← 独立启动按钮 |
| `RESET_BTN` | `PC5` | 输入，去抖 | ← 独立复位按钮；不能绕过急停/护罩/漏水 |

HX711 模块若用 5 V 供电，其数字输出不一定对 F407 安全；优先选 3.3 V 逻辑兼容接法，否则加电平转换。三台泵和 K1 均经独立驱动级；F407 GPIO 不承载电机或线圈电流。

## 5. 执行器与传感器接口

### 5.1 3 路泵驱动

- 三台独立微型蠕动泵各用一条 MOSFET/电机驱动通道；不用水路切换阀。
- 驱动输入必须兼容 F407 的 3.3 V 逻辑，建议逻辑与湿区功率侧隔离。
- 直流感性负载必须有与器件类型匹配的续流/浪涌抑制；若模块已内置，硬件队需在接线记录中标明。
- 所有输出在上电、复位、看门狗复位和调试烧录期间均应保持失能；必要时在驱动输入加硬件下拉。
- 泵的额定电压、稳定电流、启动/堵转电流必须按最终实物铭牌和实测填写，本文不猜额定值。每路做独立保险/保护和独立称重标定。

### 5.2 物理观测

| 观测 | 用途 | 是否可作为绿色闭环证据 |
|---|---|---|
| 水箱称重片 + HX711 | 独立测量实际出水质量；标定零点、比例和漂移 | 是，标定通过且软管无旁路承重时 |
| 固定 UVC 相机 | 识别任务卡/目标层；侧视跟踪湿润团 | 是，画面新鲜、ROI 可见且质量门通过时 |
| 沙芯到位 NC | 防止无容器给水 | 只作互锁，不证明剂量 |
| 护罩 NC | 防止手进入湿区/活动区 | 只作互锁 |
| 漏水 NC 干接点 | 接水盘漏水时撤销执行器许可 | 只作互锁 |
| 泵“命令已发” | 设备报告状态 | **否**，不能替代称重和视觉观测 |

P0 不引入廉价土壤湿度探头作为核心定量证据；若后续增加，只能先作为辅助趋势量，必须在目标沙样中做独立标定。

## 6. 供电与硬急停

### 6.1 分域

1. 外部合规直流电源 → 总保险 `F0` → 带防误触总开关。
2. **常供逻辑域**：独立稳压支路给 RDK X5；另一逻辑支路给 F407/HX711/按钮输入。其电压和接口严格按板卡规范。
3. **可切断执行器域**：总开关后经执行器分支保险、K1 常开主触点，再分到三台泵；每路再设与线束匹配的保护。
4. 急停时 X5、F407、相机继续供电，用于落盘故障记录；三台泵失电。

电源、保险、线径和驱动额定值必须在器件确定后按实测稳定/启动/堵转电流选型，不在没有实物数据时填写虚构数值。

### 6.2 K1 许可链

```text
K1 线圈许可 = 总开关 ON
            AND 急停通道 A 闭合
            AND 护罩常闭回路闭合
            AND F407 ACT_ENABLE 有效
```

- 急停使用机械锁存蘑菇按钮，至少两组常闭触点：A 通道硬切 K1 线圈；B 通道只读送 F407。
- `ACT_ENABLE` 经驱动晶体管/光耦控制 K1，电路设计为 F407 复位、掉电或 GPIO 高阻时 K1 必然释放；软件只能保持或撤销许可，不能旁路急停和护罩。
- 护罩打开直接释放 K1，同时送 F407 记录原因。
- 漏水回路送 F407；发现漏水立即撤销 `ACT_ENABLE` 并锁存。若最终漏水模块能提供可靠干接点，可再串入 K1 许可链。
- 该演示接线是硬切执行器的工程互锁，不宣称达到任何未经测试/认证的 PL、SIL 或安全等级。

### 6.3 失效行为

| 事件 | 硬件动作 | 固件/上位机动作 |
|---|---|---|
| 急停按下 | K1 释放，三泵母线断电 | F407 锁存；X5 记录 `ABORTED_LOCKED` |
| 护罩打开 | K1 释放 | 当前 cycle 终止，不自动续跑 |
| X5/F407 串口失联 > 1000 ms | F407 撤销 `ACT_ENABLE` | ACK 4 / link stale；恢复心跳后仍需新命令 |
| F407 复位/看门狗 | `ACT_ENABLE` 和三路 pump gate 默认低 | 上电自检、身份重验、人工 Reset 后才能重新 armed |
| 漏水 | F407 撤销 `ACT_ENABLE` | 锁存漏水；清理并检查后人工复位 |
| 称重超量/传感器超时 | 停泵、撤销许可或进入受控锁存 | 禁止把“命令完成”升级为“剂量已验证” |
| UVC 画面过期/遮挡 | 不影响硬急停 | 拒绝启动或停止本轮，状态保持非绿色 |

## 7. 端子与线束约定

建议把现场接线冻结成 5 组可拔插端子；端子编号比线色更权威：

| 端子组 | 内容 |
|---|---|
| `J1 HOST` | `PD5_TX / PD6_RX / GND`，接 USB-TTL；禁止接 VCC |
| `J2 SENSOR` | HX711、沙芯、护罩、漏水、急停辅助、Start、Reset |
| `J3 DRIVER-IN` | `P30 / P60 / P90 / ACT_ENABLE / LOGIC_GND` |
| `J4 ACT-POWER` | K1 后执行器母线与三泵分路；与弱电线束分开走线 |
| `J5 LOGIC-POWER` | F407/HX711 逻辑电源；与 X5 电源分别布线、单点汇接 |

湿区接头朝下或侧向形成滴水环；水管不得越过 X5/F407；称重平台线束必须柔软并留余量。每根线两端打印相同编号，比赛现场只按编号排故。

## 8. 上电验收顺序

1. **无执行器电源**：通断表检查电源极性、各路短路、急停/护罩 NC 回路；拍照存档。
2. **只上逻辑域**：确认三路 pump gate 与 `ACT_ENABLE` 均为失能；读取 RootScope 固件身份。
3. **串口门**：持续心跳、校验错误帧拒绝、拔 USB 后 1000 ms 内进入 link stale；禁止接泵。
4. **K1 门**：用指示灯代替执行器，验证急停、护罩、F407 复位、失联均能让 K1 释放。
5. **单路干测**：一次只接一台泵，确认极性、温升和浪涌抑制；记录实测电流后才冻结保险/线径。
6. **称重门**：做已知砝码多点标定、零点复归、软管扰动和 10 分钟漂移检查。
7. **水路门**：接水盘内逐路做启停、三泵互斥、泄漏、停泵滴漏/虹吸和空跑保护；不得接透明沙芯。
8. **整机闭环**：先完成 20 次无水循环，再完成 8 次湿式快换沙芯循环；故障注入至少覆盖拔串口、遮挡相机、打开护罩、移除沙芯、漏水和急停。

## 9. 明确禁止

- P0 不接底盘电机、IMU、LiDAR、深度相机或任何 Nav2 设备。
- F407 GPIO 不得直接驱动泵、继电器线圈或蜂鸣器等负载。
- 不得通过 USB-TTL 的 VCC 给已独立供电的 F407 反向供电。
- 不得把旧 XRD 底盘固件 build id、里程计字段或升降“ACK 已接受”描述成 RootScope 物理闭环。
- 不得只靠软件按钮实现急停，也不得让 `CLEAR_ESTOP` 自动触发泵恢复。
- 未量过实物电流、未查板卡额定和线径前，不填写电源、保险或驱动器的虚构额定值。
