# 01｜RootScope 产品定义与冻结边界

## 1. 一句话产品

RootScope 是一台固定桌面端侧灌溉控制器：它在透明薄层沙体中选择浅、中、深三个**演示坐标通道**之一，按实测储液质量变化停止给水，并用固定相机确认染色水是否在目标区域形成新的可见湿润团。

这是一项原型闭环验证，不是农业效果试验。三个通道用于展示控制、计量和验证能力，不代表任何植物的真实根系深度。

## 2. 为什么固定式是正确产品形态

移动不会直接证明水送得更准，却会引入定位、底盘、供电、碰撞、停车精度和展位人流等无关风险。固定式把 72 小时全部投入评委能直接观察的核心价值：

- 选择哪一层；
- 给了多少；
- 是否真的到达目标区域；
- 条件不可信时是否拒绝执行；
- 本轮证据能否回看。

未来可把同一控制核心接到温室阀组、滴灌支路、轨道设备或农业移动平台，但这些是产品路线图，不是本次已实现能力。

## 3. 冻结构

```text
正面

  [场景卡 / 目标选择区]       [状态灯 / Start / Reset / E-stop]
                │
                ▼
┌──────────────────────────────────────────────┐
│  固定 UVC 相机 + 恒定照明                    │
│        ┌──────────────────────────┐          │
│        │ 透明薄层快换沙体卡匣      │          │
│ Z1 ────●  浅层演示坐标             │          │
│ Z2 ────●  中层演示坐标             │          │
│ Z3 ────●  深层演示坐标             │          │
│        └──────────────────────────┘          │
│           卡匣到位开关 + 接水盘 + 漏水片      │
├──────────────────隔水板──────────────────────┤
│ 干区：RDK X5 / F407 / USB-TTL / 电源保护      │
│ 湿区：称重储液瓶 / 三路蠕动泵 / 硅胶管        │
└──────────────────────────────────────────────┘
```

### 3.1 卡匣

- 目标有效观察区约为 `260 mm × 180 mm`，沙层厚度起始目标 `20–30 mm`；最终数值必须按现有材料和渗流可见性实测后登记。
- Z1/Z2/Z3 起始机械坐标可按距沙面约 `45/90/135 mm` 布置；UI 显示的最终坐标必须来自实际测量，不照抄设计值。
- 三个进水口固定在卡匣侧壁，通过独立软管连接三个泵；不使用移动探针、滑台或夹点机构。
- 卡匣用防呆导轨和机械止挡定位，插入后触发到位开关；移除卡匣立即撤销泵许可。
- 优先选择可复制的透明成品容器改造，不在 72 小时内追求复杂 CNC 外壳。至少准备 4 个一致卡匣，另准备 1 个空卡匣用于干运行。

### 3.2 光学

- P0 只用一台固定 UVC 摄像头，同时覆盖上方场景卡 ROI 和透明沙体 ROI。
- 摄像头、白背板、灯带和卡匣机位均固定；禁止手持拍摄参与自动判定。
- 每次执行前保存基线图，泵停并等待稳定后保存结果图；目标 ROI 的变化只用于本项目同一机位、同一沙批、同一光照下的相对判断。
- 第二相机和深度相机均不是 P0；只有第一条闭环稳定后才考虑第二相机。

### 3.3 水路

- 采用一个称重储液瓶和三只独立微型蠕动泵，每只泵只连接一个深度通道；任何时刻只允许一只泵上电。
- 三泵方案省去三通阀、阀时序和串液问题；每路单独做质量标定，闭环最终仍以称重为停止依据。
- 储液瓶只由称重托盘承载，软管设置松弛 U 环，不能用绑带、侧壁或硬管旁路承重。
- 泵、接头和卡匣下方均设置接水盘；漏水传感器进水即关闭泵并锁存失败。
- 使用允许带入现场、易清洁的演示液体；液体和染色剂是否允许必须以赛事最新规则/场地方要求为准。

## 4. 计算与控制架构

```text
固定 UVC 相机 ─USB─> RDK X5
                         │
                         ├─ 场景卡/tag 可靠识别
                         ├─ 可选 BPU 分类 shadow
                         ├─ 前后图像 ROI 变化
                         ├─ 任务状态机 / Dashboard
                         └─ 本地证据 JSONL + 哈希链
                                   │
                       USB → CH340/CP2102 → 3.3 V TTL
                                   │ 0xAA55 / ACK / heartbeat
                                   ▼
                              STM32F407
                         ┌─────────┼───────────┐
                         │         │           │
                     3×泵 MOSFET  HX711      安全输入
                     单路互斥     称重       急停/漏水/卡匣
```

### 4.1 RDK X5

- 运行独立的 RootScope 服务，不启动 Nav2、SLAM、LiDAR、深度相机或底盘进程。
- P0 可用 Python + OpenCV + FastAPI/WebSocket；不为形式感强行建立大量 ROS 2 包。
- 标签是可复现的任务入口；若 BPU 模型稳定，则与标签并行并明确显示 `perception_source`，不能把标签结果伪装成模型推理。
- 所有执行命令携带 `task_id`、序号和超时；网页刷新、WebSocket 重连或重复提交不得重复泵水。

### 4.2 STM32F407

- 负责三泵互斥、泵硬超时、称重采样、急停锁存、漏水/卡匣输入、X5 心跳看门狗和固件身份。
- 上电默认泵全关、急停/执行许可未清、任务为空；不能恢复断电前的泵状态。
- 失去新鲜心跳、串口帧损坏、任务 ID/序号不符或安全输入异常时，所有泵保持关闭。
- 急停的常闭触点直接切断泵功率继电器，同时另一路输入给 F407 记录状态；软件不得成为唯一急停路径。

## 5. 最小闭环状态机

```text
BOOT_LOCKED
  -> SELF_CHECK
  -> READY
  -> TARGET_IDENTIFIED
  -> BASELINE_CAPTURED
  -> DOSING_Z1 | DOSING_Z2 | DOSING_Z3
  -> SETTLING
  -> VERIFYING
  -> TARGET_WETTING_VERIFIED
  -> READY（必须更换/确认卡匣并创建新 task_id）

任意状态 --故障--> SAFE_STOP -> ABORTED_LOCKED
```

`SAFE_STOP` 的固定动作顺序：撤销泵许可 → 三泵输出全关 → 保存故障帧与最后有效传感值 → 锁存任务失败。固定式设备没有需要自动回零的运动机构，因此不做任何“故障后自动运动”。

## 6. 完成等级

| 等级 | 必须具备的证据 | 允许的现场表述 |
|---|---|---|
| `SIMULATED_ONLY` | 假传感器/回放数据 | “软件流程演示” |
| `ACTUATOR_ACK` | F407 对选定泵命令 ACK，且安全输入有效 | “下位机已接受执行” |
| `MASS_LOSS_VERIFIED` | 稳定前后称重差达到本轮目标窗，无漏水告警 | “储液质量变化已验证” |
| `TARGET_WETTING_VERIFIED` | 上述全部通过，且目标 ROI 出现满足冻结阈值的新变化、错误层未触发排斥条件 | “本轮目标区域给水闭环已验证” |
| `ABORTED_LOCKED` | 任一门失败，泵全关且任务锁存 | “系统拒绝或中止了不可信动作” |

绿色只对应 `TARGET_WETTING_VERIFIED`。质量减少只能证明液体离开储液瓶，不能单独证明液体到达目标区域。

## 7. P0 / P1 / 禁止项

### P0 必须完成

- 一台 RDK X5、一块 F407、一条 USB-TTL；
- 一台固定 UVC 相机；
- 三通道固定注水、单泵互斥；
- 称重停止、漏水/卡匣/急停/心跳门；
- 场景 tag 可靠入口、前后 ROI 验证；
- 本地离线 Dashboard、结构化回执和追加式记录；
- 正向演示和至少一个清晰的 fail-closed 演示。

### P1 仅在 P0 连续通过后

- RDK X5 BPU 场景分类，与标签并行显示；
- 自动阈值建议，但阈值必须在冻结的本地卡匣数据上锁定；
- 第二相机或经同批沙标定的附加传感器；
- 更漂亮的外壳、灯效和证据导出页。

### 72 小时内禁止

- 轮式底盘、履带、电机、编码器、IMU；
- LiDAR、深度相机、SLAM、Nav2、路径规划；
- 移动探针、Z 轴滑台、机械臂；
- 双 X5、云端唯一链路、本地大模型自由生成；
- 没有数据来源的根深、节水率、产量提升或环境收益数字。

## 8. 诚实声明

本次可以证明的是：在受控透明沙体演示夹具中，端侧系统能按场景选择固定注水通道，以称重控制给水，并通过固定视觉验证目标区域变化，同时对指定故障 fail-closed。

本次不能证明的是：真实植物根系识别、真实农田最优灌溉、节水率、产量提升、长期防堵、户外防水、不同土壤泛化或规模化经济性。上述内容只能列为下一阶段验证计划。
