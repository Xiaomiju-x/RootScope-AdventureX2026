# RootScope 固定式灌溉舱｜执行资料入口

> 决策冻结：本项目是固定桌面灌溉舱，不是小车。P0 不使用底盘、电机、IMU、LiDAR、深度相机、SLAM、Nav2、机械臂或双 X5。

## 当前产品

**RootScope｜智能可视化根区灌溉控制器**

把看不见的“模拟根区目标层给水”，变成可见、可量、可追溯的端侧闭环：RDK X5 识别演示场景并选择浅/中/深固定注水通道；STM32F407 在急停、漏水、卡匣到位、心跳和计量条件满足时驱动对应蠕动泵；储液瓶称重记录实际质量减少；固定相机复核染色水是否在目标 ROI 形成新湿润区域。

## 队长的三条硬规则

1. 先完成一条能连续复现的物理闭环，再做 BPU 分类、第二相机或附加传感器。
2. 主界面必须显示本轮感知来源和完成等级；标签、标定、执行器 ACK、称重和视觉验证不能混为一谈。
3. 没有实测证据就不显示绿色，不宣传节水率、真实根深、农业产量或野外可用性。

## P0 成功定义

在同一固定机位、同一批沙和已登记卡匣上，完成：

`目标卡识别 → 安全基线 → 单通道定量给水 → 储液质量变化 → 目标 ROI 新湿润区域 → 本地回执`

并满足：

- 全程最多一个泵获得许可；
- 急停、通信失联、漏水、卡匣移除、称重失稳或相机过期时立即关闭所有泵并锁存失败；
- 绿色 `TARGET_WETTING_VERIFIED` 只在称重与目标 ROI 两类物理证据都通过时出现；
- 失败后不自动重启本轮，必须排障、复位、重新建立新任务 ID。
