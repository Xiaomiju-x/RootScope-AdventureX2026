# 02｜30–45 秒主演示与现场运行手册

## 1. 演示目标

评委在不理解代码的情况下，应该在 40 秒内看到五件事：

1. 目标场景被端侧识别；
2. 设备只打开对应深度通道；
3. 屏幕上的实时质量变化到达目标窗后自动停泵；
4. 染色水在透明沙体的目标区域出现；
5. 遮挡、拔线或按急停时，设备宁可不浇也不猜。

## 2. 主演示前 90 秒检查

运维宣讲同学逐项口头确认，算法界面同时显示：

- 卡匣编号、沙批编号和目标通道机械坐标已登记；
- 卡匣干燥程度在本轮允许范围，已插到底并触发到位开关；
- 接水盘干燥，漏水输入为正常；
- 储液量足够，称重 2 秒稳定窗通过，软管未拉住托盘；
- 三路泵均为 OFF，只有本轮目标路具备许可；
- 摄像头画面新鲜、无遮挡、曝光已锁定；
- F407 固件身份、心跳和安全状态新鲜；
- 蘑菇急停释放，但仍需受控 Reset 才能进入 READY；
- 本轮创建全新的 `task_id`，Dashboard 显示“真实输入”，不是 fixture/回放。

任一项失败都不临场绕过。先展示“为什么拒绝”，再由同学排障。

## 3. 40 秒正向演示

| 时间 | 观众动作/设备动作 | 屏幕必须显示 | 完成门 |
|---:|---|---|---|
| 0–3 s | 观众放入一张浅/中/深场景卡，按 Start | 场景卡画面和 `perception_source` | 卡片唯一、图像新鲜 |
| 3–7 s | X5 识别并高亮目标通道 | 目标 `Z1/Z2/Z3`、本轮目标质量、非农业处方声明 | 标签可靠路径通过；BPU 可并行 |
| 7–10 s | 自动做安全基线与前图 | 卡匣/漏水/急停/心跳/称重/相机六门全绿 | 连续稳定窗通过 |
| 10–22 s | F407 仅打开目标泵；质量曲线实时下降 | 当前泵、目标窗、实际变化、硬超时倒计时 | 另两泵保持 OFF；到目标即停 |
| 22–27 s | 泵停，等待液体与称重稳定 | `MASS_LOSS_VERIFIED` 或失败原因 | 稳定后复测，不取瞬时峰值 |
| 27–33 s | X5 比较前后固定 ROI | 前后图、目标 ROI 覆盖、错误层排斥状态 | 阈值来自冻结标定，不现场拖动 |
| 33–38 s | 生成本地回执 | 完成等级、目标/实测、时间线、版本、记录哈希 | 只有两类物证都过才绿色 |
| 38–40 s | 宣讲收束 | “受控夹具验证，不等于农田结论” | 不夸大 |

泵运行时间和目标质量必须以实测流量调整，不能为了凑 40 秒跳过硬超时或称重稳定窗。如果真实稳定闭环需要 45 秒，就把讲稿压短，不压缩安全步骤。

## 4. 8 秒失败演示

正向演示后任选一个可恢复故障，不要连续制造多个不确定状态。

### 推荐 A：移除卡匣

1. 放入目标卡并进入 READY；
2. 轻拉卡匣使到位开关断开；
3. 屏幕立即显示 `CARTRIDGE_REMOVED / ABORTED_LOCKED`；
4. 三泵输出保持 OFF；
5. 推回卡匣也不会自动继续，必须创建新任务。

优点：观众能看懂，且不需要拔带电串口。

### 推荐 B：按急停

1. 在泵运行中按下蘑菇急停；
2. 急停常闭回路直接切断泵功率；
3. F407 与 X5 记录锁存状态；
4. 释放急停后系统仍不自动恢复，Reset 后重新做自检。

### 备用 C：拔 USB-TTL

仅在备份演示台或已验证接口不会损坏时使用。预期 F407 在冻结的心跳超时内关闭泵并锁存；现场必须显示**实测停止时间**，不能照抄设计目标。

## 5. 主讲口播（约 40 秒）

“地下给水最大的问题不是看不见水管，而是看不见水是否真的到了目标区域。请任选一张演示场景卡。RDK X5 在本地识别本轮目标，STM32 只有在卡匣、漏水、急停、通信和称重都可信时，才允许一个深度通道工作。现在质量曲线达到目标，泵自动停止；固定相机再比较前后画面。只有储液质量变化和目标区域新湿润团同时通过，系统才给出绿色回执。这里的浅、中、深是受控夹具坐标，不是我们虚构的植物根深。现在我移开卡匣——它立即关泵并锁存失败。我们用 72 小时验证的是一个端侧、可量、可拒绝的灌溉控制闭环。”

## 6. 现场恢复流程

故障后按固定顺序恢复：

1. 确认三泵物理断电；
2. 处理漏水、管路、卡匣或通信根因；
3. 擦干接水盘与漏水片；
4. 检查储液瓶未被软管牵拉；
5. 更换或登记新卡匣；
6. 释放急停；
7. 受控 Reset，等待 F407 身份和安全状态；
8. 新建 `task_id`，重新拍基线，不复用失败任务；
9. 先做 2 秒无水许可测试，再开始下一轮。

## 7. 展位轮班

- 主讲：只碰场景卡、Start 和已验证的失败动作。
- 机械同学：换卡匣、擦接水盘、观察管路和固定机位。
- 硬件同学：监控电源、泵温度、称重稳定与急停；任何异常有权终止演示。
- 算法同学：观察日志和版本，不在评委到场前临时更新代码。

每完成 5 次湿运行，安排一次短检查：管路渗漏、卡匣接口、称重零点、相机固定、泵流量漂移和剩余干卡匣数量。

## 8. 演示降级口径

| 当前最高等级 | 现场怎么说 | 禁止怎么说 |
|---|---|---|
| `TARGET_WETTING_VERIFIED` | “受控夹具中的目标区域给水闭环已通过” | “已证明真实根区精准灌溉” |
| `MASS_LOSS_VERIFIED` | “定量出水已验证，目标区域视觉证据未通过” | “水已到达目标根系” |
| `ACTUATOR_ACK` | “下位机已接受动作，物理计量尚未完成” | “已精确给水” |
| `SIMULATED_ONLY` | “这是软件回放/模拟流程” | “真机闭环” |
| `ABORTED_LOCKED` | “安全门拒绝了本轮执行” | “只是 UI 报警，泵还可以继续” |
